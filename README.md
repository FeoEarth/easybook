Easybook

Easybook 是一款跨设备笔记应用，提供 Android 与 Web 客户端，支持笔记管理、富文本编辑、工作区管理及 Cloudflare 云端同步。

项目基于 Android、Web、Cloudflare构建。

项目状态
Easybook 目前处于积极开发阶段

主要功能

- Android / Web 跨设备使用
- 笔记、文件夹及富文本管理
- 工作区与同步密钥
- 账户与通行密钥认证
- 云端数据同步与附件管理
- AI / MCP 集成
