# 阶段五笔记浏览专项优化

- 画廊分离内容预览和标题／时间；图片缩略图使用现有附件读取接口，按可见区域加载、最多两项并发、缓存上限32张，失败占位保持尺寸。画廊与多选不创建滑动操作层。
- 长按显示靠近来源笔记的预览与菜单，按视口调整位置；点击外部、返回、执行操作关闭。列表保留方向锁定滑动，清理取消、滚动与快速切换残留位移；按笔记抑制合成点击，不阻断其他笔记的正常轻点。
- 删除通知约5秒，每批操作绑定独立撤销记录（最多展示3条）。撤销保留正文，恢复原文件夹、置顶／收藏标记并产生新的 dirty mutation。原文件夹已删除时恢复至未分类；操作过时或已永久删除时明确反馈失败。云端终态回执可提示撤销未生效。永久删除保留二次确认，不提供撤销。
- 多选切换列表／画廊保留选择；移动选择器统一分组列表；置顶与更新时间相同时以id稳定排序；搜索防抖且相同结果保留DOM，避免闪烁和焦点丢失。

验证：笔记管理触摸／批量操作、专项画廊与撤销测试，以及模拟原生桥接的删除回执后撤销／终态失败测试通过；检查320／390／768宽度和浅深色。未进行Android真机WebView／SQLite仪器测试；环境缺少中文字形，中文字体外观需真机确认。未修改同步协议、后端、数据库模型或附件节点，未构建APK、未部署Cloudflare。
