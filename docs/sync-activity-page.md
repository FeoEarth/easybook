# 同步活动独立页面

基线：阶段四分支 `be6f6a27d827209a6e166deb957d32db4130f647`；main 尚未合并阶段四。本次继续提交现有阶段四分支，避免 main 的自动 APK 构建。

- 将居中 dialog 替换为应用导航中的 section：返回导航、大标题、整体状态、最近成功时间、立即同步及 inset 分组列表。设置只留一个入口；列表状态也可进入，返回时恢复原页面和滚动位置。使用同 URL 的 History API，兼容 WebView 严格的原生桥 URL 校验，没有放宽原生权限。支持浏览器后退/前进和现有 Android handleBack 入口。
- 正在进行、等待同步、需要处理、最近活动独立分组，空组隐藏。紧凑图标/标题/说明/右侧操作，完成记录不显示进度；实际传输字节已知时显示百分比，未知时显示不确定进度。蓝色操作、克制的状态色，适配深色模式与减少动态效果。
- 重复空检查合并为一条“检查远端更新 · 已检查，没有新内容”。只有原有合并规则实际接纳了新笔记/更高版本时才计为下载；Web 与 Android 均只增补观察元数据，不改变 outbox、协议、cursor 推进、文档模型或传输顺序。旧记录未保存变更数量时明确标注为旧检查记录，不推断为真实下载。
- 失败任务不再因其 mutation 已退出当前待传队列而被直接过滤；重试前的错误留作诊断元数据。全部重试仅在多个未解决失败时出现。错误文案经过白名单映射，不显示原始 URL、Token 或堆栈。成功时间只由原有完整同步成功路径更新。
- 图片/附件机制、富文本源码、悬浮工具栏与待办布局保持不变。仅刷新 Android/Web UI 产物；不部署 Cloudflare，不修改 Worker API/D1/R2，不构建 APK，不添加项目依赖。

- `node scripts/sync-page-browser-test.mjs`：真实 Chromium，320/390/1024px，浅色/深色，无横向溢出、无弹窗、自然滚动及 sticky 导航、实际浏览器返回/前进和返回按钮。可用 `EASYBOOK_CHROMIUM_PATH` 指定本机浏览器。已目视检查移动端浅色/深色截图；检查环境的中文字体仅安装在临时测试目录，没有增加产品字体依赖。
