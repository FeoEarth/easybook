# UI 开发约束

- 已经专项优化的界面默认是受保护的设计基准。没有用户明确要求，不重新设计；只修复指定问题。
- Liquid Glass 材质与组件职责分离。共享 Shader、GlassBackdrop、GlassMaterial、GlassSurface、主题及基础动画，不意味着共享布局。
- Context Menu、Folder Picker、Format Panel、Attachment Menu、Bottom Sheet 保留各自的分组、尺寸、层级、交互与键盘处理。
- 玻璃优先用于外壳。内部按钮保持简洁，不将所有控件变成玻璃卡片，不将格式功能平铺成通用三列网格。
- 修改一个组件，不顺带重构其他界面。共享组件的新参数必须默认保持其他调用者的行为。
- 保护成熟的格式面板、底部浮动工具栏、文件夹层级导航、多选栏、笔记管理、附件交互、同步活动页面。
- 出现退化时先查 Git 历史，精确恢复最近成熟实现，不回退整个项目，也不重新生成替代布局。
- 格式面板保留 `index.html` 中的段落样式横向条、字符格式分段控件、列表/缩进分组、颜色子面板和“更多”。底部单行工具栏是独立组件。
- 原生格式材质适配器只接收几何与主题；不枚举格式按钮、不创建第二套命令映射、不接管选区、焦点或触摸。
- 当前格式布局基准：`39f56e13b43e6d1f6da020c086f1fdd4f0c0e41a`；其 `index.html` 与 PR #12 合并版本一致。后续用户明确授权的专项修复可更新基准。

本文件仅指导开发，不添加运行时检查或额外测试流程。
